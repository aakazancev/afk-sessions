# AFK Sessions

Все сессии Claude Code из вашего терминала — в строке меню macOS. Те, что ждут
разрешения, наверху: разрешить или отклонить можно, не переключаясь в терминал.
Отошли от мака — включите режим «Я отошёл», и один Telegram-бот поведёт все сессии.

Демо и подробности: https://aakazancev.github.io/afk-sessions/

## Скачать

https://github.com/aakazancev/afk-sessions/releases/latest

Нужно: macOS 14+ и Claude Code в терминале.

## Установка

1. Распакуйте zip и перетащите `AFKSessions.app` в «Программы».
2. Первый запуск. Приложение не подписано у Apple: попробуйте открыть его — macOS
   его заблокирует. Тогда откройте «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»
   или выполните в терминале:

   ```bash
   xattr -dr com.apple.quarantine /Applications/AFKSessions.app
   ```

3. В строке меню: «Настройки… → Подключение → Установить». Приложение добавит свои
   хуки в `~/.claude/settings.json`, остальные настройки не трогает. Новые сессии
   Claude Code появятся в панели.

## Telegram (необязательно)

1. Создайте бота у @BotFather командой `/newbot`.
2. Вставьте токен в «Настройки → Telegram».
3. Отправьте боту команду `/start <код>` — её покажут настройки.

Режим «Я отошёл» включается пилюлей в панели, командой `/afk_start` или сам при
блокировке экрана (это можно выключить в настройках Telegram). В этом режиме:

- сессия, закончившая ход, пишет в бот «готово» и ждёт вашего ответа;
- разрешения приходят кнопками «Разрешить» / «Отклонить»;
- работающей сессии можно написать — текст встанет в очередь и уйдёт после текущего хода.

`/afk_back` — выключить режим.

## Обновления

Раз в сутки приложение проверяет новую версию на GitHub и показывает ссылку в панели.
Обновить — скачать и заменить приложение в «Программах» (и снова «Всё равно открыть»).

## Удаление

1. «Настройки → Подключение → Удалить» — убирает хуки из `~/.claude/settings.json`.
2. Удалите приложение.
3. Удалите папку `~/Library/Application Support/Sessions`.
4. По желанию: удалите `~/.claude/settings.json.sessions-backup` (копия до последней
   правки) и настройки приложения — `defaults delete dev.local.afksessions`.

## Отзывы и ошибки

https://github.com/aakazancev/afk-sessions/issues — пункт «Отзыв» в панели ведёт туда же.

## Сборка из исходников

```bash
chmod +x build-app.sh
./build-app.sh
open build/AFKSessions.app
```

Требуется macOS 14+ и Xcode: скрипт собирает его тулчейном (`DEVELOPER_DIR`).
Версия задаётся одной переменной `VERSION` в `build-app.sh` и попадает в `Info.plist`.
`./build-app.sh --release` дополнительно собирает zip для релиза в `dist/`.

## Как это устроено

```
Claude Code ──хук──> sessions-cli ──TCP 127.0.0.1──> AFKSessions.app
                          ↑                                   │
                          └──────── решение ──────────────────┘
```

- `sessions-cli` вызывается из хуков, читает JSON со stdin и шлёт событие
  приложению одной строкой JSON.
- На `PermissionRequest` (Claude Code спрашивает «можно?») CLI **блокируется** и ждёт
  ответа. Нажали «Разрешить» — CLI печатает решение (allow/deny) в `hookSpecificOutput`,
  и агент продолжает. Вне режима «Я отошёл» ответа ждут 5 минут, потом Claude Code
  спросит в терминале как обычно.
- В авто-режимах CLI не вмешивается: при `permission_mode` `bypassPermissions` /
  `auto` / `dontAsk` / `plan` сразу выходит, в `acceptEdits` — пропускает правки файлов.
- На `Stop` CLI тоже ждёт ответа, но держит сессию только в режиме «Я отошёл»:
  ваш ответ из Telegram становится следующим указанием. Вне режима приложение
  отвечает сразу, и сессия заканчивает ход как обычно.
- Остальные хуки (`SessionStart`, `UserPromptSubmit`, `PostToolUse`, `Notification`,
  `SubagentStart`, `SubagentStop`, `SessionEnd`) только сообщают о событиях.
- Приложение слушает случайный порт на 127.0.0.1. Порт и токен лежат в
  `~/Library/Application Support/Sessions/endpoint` с правами 0600.

**Важное свойство:** если приложение не запущено, CLI молча выходит с кодом 0
и пустым stdout. Claude Code в этом случае спрашивает разрешение как обычно.
Сломать рабочий процесс выключенное приложение не может.
